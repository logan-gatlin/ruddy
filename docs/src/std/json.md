# [std](bundle.md)::json

`json` parses, inspects, encodes, and decodes JSON documents.

JSON text can be decoded directly into an expected Ruddy type.

```ruddy
let names: Result [String] std::json::Error =
  std::json::decode "[\"Ada\",\"Grace\"]"
```

## Types

### Error

```ruddy
type Error = #Derive codec::DeriveError | #Codec codec::Error
```

Why JSON could not be read or written: the type has no default codec, or the codec or the document failed, at a path.

### Limits

```ruddy
type Limits = { depth: Nat, bytes: Nat, members: Nat, digits: Nat }
```

What a reader refuses before it allocates: input longer than `bytes`, nesting deeper than `depth`, a record or array with more than `members` members, or a number token with more than `digits` digits.

### Number

```ruddy
type Number = { token: String }
```

A JSON number as written: the token, kept exactly until a conversion is asked for and checked.

### Value

```ruddy
type Value =
  | #Null
  | #Bool Bool
  | #Number Number
  | #String String
  | #Array [Value]
  | #Object [(String, Value)]
```

JSON data as immutable, pattern-matchable values. Objects keep their members in order, repeated keys among them; numbers keep their spelling.

## Values

### canonical

```ruddy
let canonical: Value -> Value
```

A document in the named canonical profile `sorted-members-1`: object members ordered by key, by scalar value, keeping repeated keys in their order; no whitespace; numbers as the encoder spelled them. Two encodings of one value under this profile are one text, byte for byte.

### decode

```ruddy

```

Read a value of the inferred type from a JSON document with its default codec. See `decode_with`.

### decode_with

```ruddy
let decode_with: codec::Decoder 'a -> Limits -> String -> Result 'a Error
```

Read a value with a decoder from a JSON document, within the limits: the strict structural profile, which takes records as objects, sums as `{ "tag", "value" }` objects, and refuses unknown, repeated, and missing fields, and anything after the one document.

### default_limits

```ruddy
let default_limits: Limits
```

The default limits for JSON input: 512 levels, 64 MiB, 1,000,000 members, and 400 digits per number.
