# [std](bundle.md)::[path](path.md)::posix

`posix` manipulates paths with POSIX conventions regardless of the host platform.

A path can be normalized with POSIX conventions on every platform.

```ruddy
let logs = std::path::posix::normalize "/srv/ruddy/../logs/app.log"
```
