# [std](bundle.md)::cell

`cell` creates and updates mutable cells whose effects stay within a tracked region.

A mutable running total can be updated with a function.

```ruddy
let add_fee = fn subtotal => do
  let total = std::cell::new subtotal
  return std::cell::update (fn value => std::nat::add value 5n) total
end
```
