# [std](bundle.md)::optic

`optic` focuses immutable reads and updates through composable lenses and prisms.

A lens can focus a nested field for both observation and replacement.

```ruddy
let name = std::optic::view name_lens person
let renamed = std::optic::set name_lens "Grace" person
```

## Types

### Lens

```ruddy
type Lens 'whole 'part = {
  view: 'whole -> 'part,
  set: 'part -> 'whole -> 'whole,
}
```

A total focus into part of an immutable value. Lawful lenses restore a whole when its viewed part is set, view a part just set, and let the last set win.

### Prism

```ruddy
type Prism 'whole 'part = {
  preview: 'whole -> Option 'part,
  review: 'part -> 'whole,
}
```

A focus into one alternative of an immutable value. Lawful prisms preview values they review, and leave values outside their alternative unchanged when transformed.

### preview

```ruddy

```

Returns the part selected by a prism, or `#None` when its alternative does not match.

### prism


Creates a prism from functions that preview its alternative and construct that alternative.

### review
