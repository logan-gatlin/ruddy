# [std](bundle.md)::io

`io` writes text to standard output and standard error through the `IO` effect.

A greeting can be written as a line on standard output.

```ruddy
let greet = fn name =>
  std::io::println (std::str::concat "Hello, " name)
```

## Effects

### IO

```ruddy
effect IO = { write: String -> (), write_error: String -> () }
```
