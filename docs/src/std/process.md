# [std](bundle.md)::process

`process` reads process state and can exit the process.

An environment variable lookup can return optional text or a process error.

```ruddy
let home = std::process::env "HOME"
```

## Types

### Error

```ruddy
type Error = { kind: ErrorKind, message: String }
```

A process information failure with its kind and host message.

### ErrorKind

```ruddy
type ErrorKind = #InvalidName | #Unavailable | #Other
```

The kinds of failure reported while reading process information.

## Effects

### Exit

```ruddy
effect Exit = Nat -> |
```

Stops the process with a natural-number status.

### Process

```ruddy
effect Process = {
  args: () -> [String],
  env: String -> Result (Option String) Error,
  cwd: () -> Result String Error,
}
```

Read the host process. A local handler can supply arguments, environment, and a working directory.

## Values

### args

```ruddy
let args: () -> [String] + !Process
```

Application arguments, excluding the Node executable and script path.

### cwd

```ruddy
let cwd: () -> Result String Error + !Process
```

The process working directory.

### env

```ruddy
let env: String -> Result (Option String) Error + !Process
```

The value of an environment variable, or `#None` when it is not set.

### exit

```ruddy
let exit: Nat -> | + !Exit
```

Stops the process with the supplied status and never resumes.
