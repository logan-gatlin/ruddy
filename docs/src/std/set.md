# [std](bundle.md)::set

`set` stores distinct elements in a persistent hash array mapped trie.
Updates share unchanged branches; earlier versions remain available.

Ordinary operations treat unhashable elements as absent and skip invalid insertions.
The corresponding `try_*` functions report hashing errors. Set algebra reuses
accepted elements' cached hashes and needs no fallible variants.
Traversal order is unspecified; `equal` compares contents.

```ruddy
let active = std::set::from_array [1n, 2n, 2n]
let remaining = std::set::difference active (std::set::from_array [2n])
```
