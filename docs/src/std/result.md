# [std](bundle.md)::result

`result` defines and transforms successful or failed results.

An error can be transformed without changing a successful value.

```ruddy
let readable_response =
  std::result::map_error (fn _ => "Request failed") response
```

## Types

### Fallible

```ruddy
type Fallible 'error 'rest = #Error 'error | ..'rest
```

An open sum that may contain an error.

### Result

```ruddy
type Result 'some 'error = #Some 'some | #Error 'error
```

A successful value or an error.
