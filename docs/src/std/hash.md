# [std](bundle.md)::hash

`hash` provides pure, seeded structural hashing for collection keys.

Equal supported values at a shared static type hash equally with the same seed.
Hashes are noncryptographic and are not persistent fingerprints.

Arrays retain element order; records use alphabetical field names; sums hash
the active case name and payload. Tags, lengths, and names frame the input.
NaNs and encountered opaque values fail with a field/case/index path. Signed
zeros hash equally. Empty arrays and inactive unsupported cases can succeed.

```ruddy
let key_hash = std::hash::hash { name: "Ada", age: 37n }
```

## Types

### Error

```ruddy
type Error = { path: [PathElement], kind: ErrorKind }
```

A hashing failure, with its root-to-leaf location. No partial hash is returned.

### ErrorKind

```ruddy
type ErrorKind = #NaN | #Unsupported Unsupported | #InvalidView
```

Why hashing failed. NaNs are not equal to themselves; opaque values cannot be inspected. InvalidView indicates a reflected field or case could not be read.

### PathElement

```ruddy
type PathElement = #Field String | #Case String | #Index Nat
```

One step from the root value to a hashing error; array indices are zero-based.

### Unsupported

```ruddy
type Unsupported = #Function | #Hidden | #Mirror | #Foreign
```

A shape whose value cannot be read through typed reflection. Cells use Foreign.

## Values

### default_seed

```ruddy
let default_seed: Nat64
```

The fixed FNV-1a 64 offset basis used by hash. A seed is accumulator initialization, not a secret-key security guarantee.

### hash

```ruddy
let hash: 'a -> Result Nat64 Error
```

Hash at the value's inferred static type using default_seed. A collection must still compare keys when hashes match.

### hash_seeded

```ruddy
let hash_seeded: Nat64 -> 'a -> Result Nat64 Error
```

Hash at the value's inferred static type with an explicit seed. Equal supported values at a shared type produce equal hashes for the same seed.

### hash_with

```ruddy
let hash_with: Mirror 'a -> Nat64 -> 'a -> Result Nat64 Error
```

Hash through an explicit mirror and Nat64 seed. Traversal follows the value: empty arrays and inactive unsupported cases succeed. Unsupported values and NaNs fail at their path; signed zeros hash equally. Pure FNV-1a 64 hashing, without a persistence or hostile-collision guarantee.
