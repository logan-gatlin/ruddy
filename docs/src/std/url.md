# [std](bundle.md)::url

`url` parses and resolves URLs and provides immutable operations on their query parameters.

An absolute URL can be parsed into a validated snapshot.

```ruddy
let endpoint = std::url::parse "https://api.example.com/users?page=2"
```

## Types

### Error

```ruddy
type Error = { input: String, message: String }
```

A URL failure with the invalid input and host message.

### Query

```ruddy
type Query = [(String, String)]
```

Ordered query parameters that may contain repeated names.

### Url

```ruddy
type Url = {
  href: String,
  origin: String,
  protocol: String,
  username: String,
  password: String,
  host: String,
  hostname: String,
  port: String,
  pathname: String,
  search: String,
  hash: String,
}
```

An immutable snapshot of a WHATWG URL. Parse or resolve again to validate edits.
