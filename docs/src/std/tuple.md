# [std](bundle.md)::tuple

`tuple` constructs, reads, swaps, and transforms tuple values.

The second value of a pair can be transformed without changing the first.

```ruddy
let updated_price = std::tuple::map_second
  (fn cents => std::nat::add cents 200n)
  ("coffee", 300n)
```
