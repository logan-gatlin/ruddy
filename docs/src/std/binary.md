# [std](bundle.md)::binary

`binary` encodes and decodes typed values in a positional binary format.

A record can be encoded with its default positional binary codec.

```ruddy
let packet = std::binary::encode { sequence: 7n, message: "ready" }
```

## Types

### Error

```ruddy
type Error = #Derive codec::DeriveError | #Codec codec::Error
```

Why a binary document could not be read or written: the type has no default codec, or the codec or the input failed, at a path.

### Limits

```ruddy
type Limits = { depth: Nat, bytes: Nat, members: Nat }
```

What a reader refuses before it allocates: input longer than `bytes`, nesting deeper than `depth`, or a sequence longer than `members`.

### Schema

```ruddy
type Schema = { id: String, version: Nat }
```

An application-owned identity for a wire schema, written before a versioned document and checked when one is read. Editing a type does not change it: the application says when its schema changed.

## Values

### decode

Read a value of the inferred type from positional binary with its default codec. See `decode_with`.

### decode_versioned

```ruddy
let decode_versioned: Schema -> codec::Decoder 'a -> Limits -> [Nat8] -> Result 'a Error
```

Read a value with a decoder after checking the schema written before it: another identity or version is refused before any of the value is read.

### decode_with

```ruddy
let decode_with: codec::Decoder 'a -> Limits -> [Nat8] -> Result 'a Error
```

Read a value with a decoder from positional binary, within the limits. The decoder's schema says what comes next: nothing in the input does. The input is measured before any of it is read, so a document past the byte budget costs nothing to refuse.

### default_limits

```ruddy
let default_limits: Limits
```

The default limits for binary input: 512 levels, 64 MiB, and 1,000,000 sequence members.

### encode

```ruddy
let encode: 'a -> Result [Nat8] Error
```

Write a value as positional binary with its type's default codec. See `encode_with`.

### encode_versioned

```ruddy
let encode_versioned: Schema -> codec::Encoder 'a -> Limits -> 'a -> Result [Nat8] Error
```

Write a value with an encoder after its schema's identity and version, so a reader can tell what it holds before reading it.

### encode_with

```ruddy
let encode_with: codec::Encoder 'a -> Limits -> 'a -> Result [Nat8] Error
```

Write a value with an encoder as positional binary, within the limits: no names or tags, only what the schema says comes next, little-endian, with `Nat` and `Int` as 64 bits, `Real` as its bits, text as a 32-bit length and UTF-8, sequences as a 32-bit count and their elements, and cases as their 32-bit index in the schema. On failure there is no output.
