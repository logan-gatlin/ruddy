# [std](bundle.md)::[path](path.md)::windows

`windows` manipulates paths with Windows conventions regardless of the host platform.

A path can be normalized with Windows conventions on every platform.

```ruddy
let logs = std::path::windows::normalize "C:\\ruddy\\..\\logs\\app.log"
```
