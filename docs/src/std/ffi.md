# [std](bundle.md)::ffi

`ffi` marks immediate foreign effects and converts values at foreign boundaries.

A foreign value can be checked against an expected record shape.

```ruddy
let preferences: Result { dark_mode: Bool } std::ffi::DecodeError =
  std::ffi::decode foreign_preferences
```

## Types

### DecodeError

```ruddy
type DecodeError = { path: String, expected: String, message: String }
```

Why a value could not cross a foreign boundary, including its position and expected shape.
