# [std](bundle.md)::http

`http` sends buffered requests and provides helpers for common responses.

A buffered `GET` request can use the default options.

```ruddy
let response = std::http::get "https://api.example.com/health"
```

### Request

```ruddy

  url: String,
  method: String,
  headers: Headers,
  body: Body,
  timeout_ms: Nat,
  max_bytes: Nat,
  redirect: Redirect,
}
```

Buffered request. timeout_ms includes reading the body; max_bytes bounds the response body.
