# [std](bundle.md)::option

`option` defines optional values and functions for transforming and combining them.

A fallback can replace an absent optional value.

```ruddy
let display_name = std::option::unwrap_or "Guest" saved_name
```

## Types

### Maybe

```ruddy
type Maybe 't = #Nil | ..'t
```

An open sum that may contain `#Nil`.

### Option

```ruddy
type Option 't = #Some 't | #None
```

A value that is either present as `#Some` or absent as `#None`.
