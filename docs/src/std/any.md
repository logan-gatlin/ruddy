# [std](bundle.md)::any

`any` packages a value with its type and recovers it through an exact type check.

A packaged value can be recovered when the requested type matches exactly.

```ruddy
let stored = std::any::upcast "ready"
let status: Option String = std::any::downcast stored
```

## Types

### Any

```ruddy
type Any = hide 'a => { mirror: Mirror 'a, value: 'a }
```

A value of any type, packaged with the mirror of that type: opened by `downcast`, or by a `hide` pattern, which makes the mirror evidence for the value's type.

## Values

### downcast

```ruddy
let downcast: Any -> Option 'a
```

The value packaged, when its type is exactly the one asked for: the same structure, primitives, and effect contracts. Nothing is converted.

### upcast

```ruddy
let upcast: 'a -> Any
```

Package a value with the mirror of its type.
