# [std](bundle.md)::any

`any` packages a value with its type and recovers it through an exact type check.

A packaged value can be recovered when the requested type matches exactly.

```ruddy
let stored = std::any::upcast "ready"
let status: Option String = std::any::downcast stored
```

## Types

### Any

```ruddy
type Any = hide 'a => { mirror: TypeInfo 'a, value: 'a }
```

A value packaged with authenticated descriptive evidence of its type, including functions and opaque values. The historical `mirror` field is `TypeInfo`: opening it grants observation and exact casting, without constructor authority.

## Values

### downcast

```ruddy
let downcast: Any -> Option 'a
```

The value packaged, when its type is exactly the one asked for: the same structure, primitives, and effect contracts. Nothing is converted.

### upcast

```ruddy
let upcast: 'a -> Any
```

Package a value with descriptive evidence of its static type.
