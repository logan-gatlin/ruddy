# [std](bundle.md)::function

`function` provides combinators for applying, composing, and adapting functions.

Two transformations can be composed into one function.

```ruddy
let double_after_increment = std::function::compose
  (fn value => std::nat::multiply value 2n)
  (fn value => std::nat::add value 1n)
```

## Values

### apply


### compose

```ruddy
let compose: ('b -> 'c + ..'effects) -> ('a -> 'b + ..'effects) -> 'a -> 'c + ..'effects
```

Combines two functions so the result of the second becomes the argument of the first.

### constant
