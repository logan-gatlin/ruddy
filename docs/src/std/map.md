# [std](bundle.md)::map

`map` stores persistent key/value associations in a hash array mapped trie.
Updates share unchanged branches; earlier versions remain available.

Ordinary operations treat unhashable keys as absent and skip invalid insertions.
The corresponding `try_*` functions return `hash::Error` for diagnostic use.
Values need not be hashable. Traversal order is unspecified; use `equal_by`
to compare contents rather than generic structural comparison.

```ruddy
let first = std::map::from_array [("Ada", 37n)]
let second = std::map::insert "Grace" 42n first
let age = std::map::get "Ada" second
```

A persistent map with hidden storage. Use the module functions to preserve its key and hash invariants. Keys use structural equality and the fixed default hash seed; values are unrestricted.
