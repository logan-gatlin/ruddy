# [std](bundle.md)::random

Noncryptographic random primitives and reproducible local streams.

`local` draws one seed from its outer Random handler, then owns its stream.
`with_seed` establishes a repeatable root without drawing an outer seed.
Assign task seeds in stable order before scheduling concurrent work.

```ruddy
let roll = fn _ => std::random::with_seed 42n64 (fn _ =>
  std::random::local (fn _ => std::random::nat_below 6n64)
)
```

## Effects

### Random

```ruddy
effect Random = {
  word64: () -> Nat64,
  boolean: () -> Bool,
  real: () -> Real,
}
```

Noncryptographic random primitives. Local handlers may supply each operation independently.

## Values

### boolean

```ruddy
let boolean: () -> Bool + !Random
```

Draws a boolean. Performs Random.boolean; built-in handlers consume one word and use its top bit.

### choose

```ruddy
let choose: ['a] -> Option 'a + !Random
```

Chooses an array position without changing the input. Empty arrays return None; singletons return their item; neither draws. Duplicate values retain their positional weight. Uses nat_below and accepts any element type.

### local

```ruddy
let local: (() -> 'a + !Random + ..'b) -> 'a + !Random + ..'b
```

Draws exactly one seed from the nearest outer Random.word64 before running the body with private state. Even empty or aborting bodies consume a seed. Later draws and nested local streams use private state. Assign seeds in stable order before concurrent work; callbacks establish their handler when invoked.

### nat_below

```ruddy
let nat_below: Nat64 -> Option Nat64 + !Random
```

Samples below an exclusive Nat64 bound. Zero returns None; one returns Some 0n64; neither draws. Rejection sampling avoids modulo bias for uniform source words, with fewer than two expected draws. A custom source that always supplies rejected words may not terminate.

### real

```ruddy
let real: () -> Real + !Random
```

Draws a Real in [0, 1). Performs Random.real; built-in handlers consume one word and use its top 53 bits.

### with_seed

```ruddy
let with_seed: Nat64 -> (() -> 'b + !Random + ..'c) -> 'b + !Random (when 'a) + ..'c
```

Runs a computation with fresh private SplitMix64 state. All primitive draws share a stream; identical seeds and ordered calls have stable results across backends. Consumes no outer randomness, preserves unrelated effects, and is noncryptographic.

### word64

```ruddy
let word64: () -> Nat64 + !Random
```

Draws a Nat64, including both endpoints of its domain. Performs Random.word64.
