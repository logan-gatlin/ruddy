## Baseline repair (preliminary commit)
- `just test` now takes filter args (`just test ir::`), still inside the memory scope.
- `UncheckedArtifact::validate` decodes the S-expression tree directly (`text::decode`, expanding compact `Raw` type nodes) instead of printing text; the printer's `block` builder is iterative (`nested` + `op(value, blocks)`); pretty-printing a 30k-deep block is quadratic because of indentation, so validation must never render.
- Hand-built artifacts in tests: `UncheckedArtifact { .. }.validate()` (strict) or `.recover()` (tolerant, drops malformed declarations with `RecoveryFact`s); `Artifact::to_unchecked()` to mutate a compiled one. `Artifact::header()`/`lir()` accessors.
